## 三、系统功能演示

### 3.1 API接口

```bash
# 健康检查
GET /api/course/health

# 生成课程
POST /api/course/generate
{
  "user_question": "分数的加减法怎么做？",
  "subject": "数学",
  "grade_level": 3
}

# 课程列表
GET /api/course/list

# 课程详情
GET /api/course/:courseId
```

### 3.2 Web界面功能

- 问题输入框
- 学科/年级选择
- 示例问题快捷按钮
- 课程展示（5个章节）
- 章节折叠/展开
- 阅读进度跟踪
- 历史记录查看
- 课程复制功能
