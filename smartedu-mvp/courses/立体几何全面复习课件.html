小学6年级数学 · 长方体、正方体、圆柱、圆锥

📚 核心概念与公式

📦 长方体

特征：6个长方形面，相对面相等，12条棱分3组
表面积：S = 2(ab + ah + bh)
体积：V = abh
其中：a=长，b=宽，h=高

🎲 正方体

特征：6个完全相同的正方形面，12条棱相等
表面积：S = 6a²
体积：V = a³
其中：a=棱长

🔵 圆柱

特征：两个相等圆形底面，侧面展开为长方形
侧面积：S侧 = 2πrh 或 πdh
表面积：S = 2πr² + 2πrh
体积：V = πr²h
其中：r=半径，d=直径，h=高

🔺 圆锥

特征：一个圆形底面，侧面展开为扇形
体积：V = ⅓πr²h
重要关系：圆锥体积 = 等底等高圆柱体积的⅓
其中：r=半径，h=高

💡 重要知识点（基于最新教学资料）

  • 等底等高关系：圆柱体积是圆锥体积的3倍（圆锥体积 = 圆柱体积÷3）
  • 表面积特殊情况：无盖水桶只算侧面积+一个底面积；通风管只算侧面积
  • 体积单位换算：1升 = 1000毫升，1毫升 = 1立方厘米，1升 = 1立方分米
  • 熔铸问题：体积守恒，形状改变但体积不变
  • 切割问题：横切圆柱增加2个底面积，纵切增加2个长方形侧面
  • 展开图：圆柱侧面沿高展开是长方形，圆锥侧面展开是扇形

🔢 立体几何解题五步法

1
识别图形：确定是长方体、正方体、圆柱还是圆锥
2
确定条件：找出边长、半径、高度等已知数据
3
选择公式：根据题目要求选择表面积或体积公式
4
统一单位：确保所有数据单位一致后再计算
5
检验答案：代入验算，检查结果是否合理

计算示例

长=12cm，宽=8cm，高=6cm

表面积 = 2×(12×8 + 12×6 + 8×6) = 432cm²

体积 = 12×8×6 = 576cm³

正方体示意图

计算示例

棱长=5cm

表面积 = 6×5² = 150cm²

体积 = 5³ = 125cm³

圆柱示意图

计算示例

半径=4cm，高=10cm

表面积 = 2π×4² + 2π×4×10 ≈ 351.86cm²

体积 = π×4²×10 ≈ 502.65cm³

圆锥示意图

计算示例

半径=5cm，高=9cm

体积 = ⅓×π×5²×9 ≈ 235.62cm³

注：圆锥体积是等底等高圆柱的⅓

📝 练习测试

基础计算题

题目1：长方体表面积和体积

一个长方体，长8厘米，宽6厘米，高5厘米。
求：(1) 表面积 (2) 体积

题目2：正方体计算

一个正方体的棱长是4分米。
求：(1) 表面积 (2) 体积

题目3：圆柱体积

一个圆柱的底面半径是3厘米，高是10厘米。
求它的体积（保留两位小数）。

题目4：圆锥体积

一个圆锥的底面半径是5厘米，高是9厘米。
求它的体积（保留两位小数）。

应用题

题目5：无盖水桶问题

一个无盖圆柱形水桶，底面直径是4分米，高是5分米。
做这个水桶需要多少铁皮？（保留两位小数）
提示：无盖水桶表面积 = 侧面积 + 一个底面积

题目6：熔铸问题

把一个底面半径6厘米、高12厘米的圆柱形橡皮泥，
捏成一个底面半径相同的圆锥，这个圆锥的高是多少厘米？
提示：体积守恒，圆柱体积 = 圆锥体积

题目7：沙堆重量问题

一个圆锥形沙堆，底面周长是12.56米，高是1.5米。
如果每立方米沙子重1.5吨，这堆沙子重多少吨？
提示：先求半径，再求体积，最后求重量

⚠️ 易错点提醒

  • • 单位陷阱：半径与直径要分清，r = d÷2
  • • 公式混淆：圆锥体积公式有⅓，不要漏掉
  • • 表面积陷阱：无盖水桶只算一个底面积，通风管只算侧面积
  • • 等底等高：圆锥体积 = 等底等高圆柱体积的⅓
  • • 熔铸问题：体积守恒是关键，形状改变但体积不变
  • • 切割问题：横切圆柱增加2个底面积，纵切增加2个长方形面
