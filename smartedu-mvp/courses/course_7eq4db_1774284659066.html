圆的周长

让我们一起探索圆形的奥秘，学习如何计算圆的周长吧

什么是圆的周长

小朋友们，想象一下

圆的周长就像是一个小蚂蚁绕着圆形饼干走一圈的路程！
从起点出发，沿着圆形的边缘走，最后回到起点，这就是圆的周长。

1

认识直径

直径是通过圆心的直线，把圆分成两半。如果圆是一个大饼，直径就是从一边切到另一边最长的那一刀！

2

神奇的圆周率

圆周率用希腊字母π表示，约等于3.14。这是一个神奇的数字：不管圆有多大或多小，周长除以直径永远约等于3.14！

3

周长公式

圆的周长 = 圆周率 x 直径，或者写成：周长 = 2 x 圆周率 x 半径

C = π × d 或 C = 2 × π × r
C表示周长，d表示直径，r表示半径，π约等于3.14

互动演示

观察小技巧

拖动滑块改变圆的大小，看看周长是怎么变化的。你会发现：圆越大，周长也越大，而且周长大约是直径的3.14倍！

练习巩固

1

这个圆的直径是 10厘米，请计算它的周长是多少厘米？
（保留一位小数，π取3.14）

2

这个圆的半径是 5米，请计算它的周长是多少米？
（保留一位小数，π取3.14）

3

一个圆形花坛的直径是 6米，小明想绕花坛走一圈，他需要走多少米？
（保留一位小数，π取3.14）
