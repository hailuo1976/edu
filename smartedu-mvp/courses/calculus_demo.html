📚 概念讲解

🔵 导数概念

导数描述函数在某一点的瞬时变化率，即曲线在该点切线的斜率。

f'(x) = limh→0 [f(x+h) - f(x)] / h

几何意义：切线的斜率
物理意义：瞬时速度

🟢 积分概念

积分是导数的逆运算，表示曲线下的面积累积。

∫f(x)dx = F(x) + C

几何意义：曲线下的面积
物理意义：位移、总量

🟣 基本公式

幂函数导数：

(xn)' = n · xn-1

幂函数积分：

∫xndx = xn+1/(n+1) + C
