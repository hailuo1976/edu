什么是循环

循环是程序设计中的一种基本控制结构，它允许一段代码被重复执行多次，直到满足特定的终止条件为止。

for循环
已知次数
while循环
条件控制

for 循环语法

1 for (初始化; 条件; 更新) {
2 // 循环体
3 循环语句;
4 }

执行流程

1
初始化变量
2
判断条件
3
执行循环体
4
更新变量

循环可视化

1 for (let i = 0; i < 5; i++) {
2 drawCircle(i);
3 }
当前迭代 0
变量 i 值 0
条件 i < 5 true

练习：计算求和

请编写一个 for 循环，计算从 1 加到 10 的和。 正确答案应该是 55。

1 let sum = 0;
2 for (let i = 1; i <= 10; i++) {
3 sum += i; // 累加
4 }
