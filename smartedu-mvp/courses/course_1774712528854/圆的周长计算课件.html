🔵 圆的周长

小学数学 · 探索圆周率π的奥秘

概念讲解

什么是圆的周长？

圆的周长是指围绕圆形一周的闭合曲线长度，数学上称为"圆周"。想象一下，如果你沿着圆形跑道走一圈，走过的距离就是这个圆的周长。

🔢 认识圆周率π

圆周率是指圆的周长与直径的比值，用希腊字母π表示。这是一个神奇的数据——无论圆的大小如何，周长除以直径的值永远是π！

π ≈ 3.14159265358...

✨ 小知识：圆周率是一个无限不循环小数，在实际计算中我们通常取近似值 π ≈ 3.14

📐 圆的周长计算公式

C = π × d

或

C = 2 × π × r
其中：
C 表示圆的周长
d 表示圆的直径
r 表示圆的半径
π 表示圆周率（约等于3.14）
记忆小技巧

🎯 因为直径 = 2 × 半径（d = 2r），所以两个公式是等价的！

🎯 已知直径用 C = πd，已知半径用 C = 2πr

🎯 圆的周长大约是直径的3.14倍，或半径的6.28倍

公式的由来

古代数学家通过大量的测量发现：圆的周长和直径的比值总是接近一个固定的数。中国的《周髀算经》中就有"周三径一"的说法，意思是圆的周长大约是直径的3倍。

后来，数学家们通过精密计算，发现这个比值约等于3.14159...，这就是我们所说的圆周率π。

3 一个圆形桌面的周长是157厘米，这个桌面的直径是多少厘米？（π取3.14）
厘米
解题提示

已知周长，求直径，可以用公式的变形：

C = πd → d = C ÷ π

d = 157 ÷ 3.14 = 50 厘米

4 一个圆形游泳池的半径是20米，小红沿着游泳池边缘走了一圈，她走了多少米？（π取3.14）
米
解题提示

走一圈的距离 = 圆的周长

已知半径 r = 20 米

C = 2 × 3.14 × 20 = 125.6 米

5 一个圆形钟表的周长是62.8厘米，这个钟表的半径是多少厘米？（π取3.14）
厘米
解题提示

已知周长，求半径，可以用公式的变形：

C = 2πr → r = C ÷ (2π) = C ÷ 2 ÷ π

方法一：先求直径 d = 62.8 ÷ 3.14 = 20 厘米

方法二：直接求半径 r = 62.8 ÷ 3.14 ÷ 2 = 10 厘米

学习要点总结

✅ 圆的周长公式：C = πd 或 C = 2πr

✅ 圆周率π ≈ 3.14，是周长与直径的比值

✅ 已知周长求直径：d = C ÷ π

✅ 已知周长求半径：r = C ÷ π ÷ 2
