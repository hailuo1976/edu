概念讲解

🎯 什么是泛函分析？

泛函分析是研究无限维线性空间上的函数（泛函）和算子的数学分支。它将线性代数和数学分析的方法推广到无限维空间，是现代分析数学的基础。

📏 范数的定义

设 X 是一个向量空间，若对于每个 x ∈ X，都有一个实数 ||x|| 与之对应，满足：

||·|| : X → ℝ

✅ 范数三大性质

  • 非负性：||x|| ≥ 0，且 ||x|| = 0 ⟺ x = 0
  • 齐次性：||αx|| = |α|·||x||，∀α ∈ ℝ
  • 三角不等式：||x + y|| ≤ ||x|| + ||y||

🌐 常见范数示例

在 ℝⁿ 中，常用的范数包括：

p-范数：||x||p = (∑|xᵢ|p)1/p

特别地，p=2时为欧几里得范数

📖 定义：度量空间

设 X 是一个非空集合，若存在一个映射 d: X × X → ℝ，满足以下条件，则称 (X, d) 为度量空间：

  • 非负性：d(x, y) ≥ 0，d(x, y) = 0 ⟺ x = y
  • 对称性：d(x, y) = d(y, x)
  • 三角不等式：d(x, z) ≤ d(x, y) + d(y, z)

📚 重要定理：完备性

巴拿赫空间：一个完备的赋范向量空间称为巴拿赫空间。完备性意味着每个柯西序列都收敛。

希尔伯特空间：具有内积结构的完备空间，记作 (H, ⟨·,·⟩)。

📝 范数空间的判定步骤

1
验证非负性：证明对于任意 x ∈ X，有 ||x|| ≥ 0，且 ||x|| = 0 当且仅当 x = 0（零向量）。
2
验证齐次性：证明对于任意标量 α ∈ ℝ（或 ℂ）和向量 x ∈ X，有 ||αx|| = |α|·||x||。
3
验证三角不等式：证明对于任意 x, y ∈ X，有 ||x + y|| ≤ ||x|| + ||y||。这通常需要用到闵可夫斯基不等式。
