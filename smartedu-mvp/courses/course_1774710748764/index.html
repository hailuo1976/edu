一、导数的概念

📖 什么是导数？

导数是微积分中最重要的概念之一，它描述了函数在某一点的瞬时变化率。 简单来说，导数告诉我们：当自变量发生微小变化时，因变量会以多快的速度变化。

导数的概念源于人们对"变化"和"速度"的思考。从物理学的角度看，导数可以帮助我们理解：

  • 🚗 汽车的瞬时速度（位移对时间的导数）
  • ⚡ 加速度（速度对时间的导数）
  • 📈 股票价格的变化趋势
  • 📉 边际成本、边际收益等经济概念

导数的定义公式

f'(x) = limΔx→0 [f(x+Δx) - f(x)] / Δx
也可以记作：dy/dx 或 df/dx，表示y对x的变化率

📌 几何意义

导数的几何意义是函数图像在某点处的切线斜率。切线斜率反映了曲线在该点的倾斜程度和变化方向。

几何直观：f'(a) = 曲线y=f(x)在点(a,f(a))处的切线斜率

📌 物理意义

在物理学中，导数表示瞬时变化率。例如：

  • 速度 = 位移对时间的导数
  • 加速度 = 速度对时间的导数
  • 功率 = 功对时间的导数

📌 极限思想

导数的核心是极限思想：当Δx无限趋近于0时，平均变化率趋近于瞬时变化率。

从"平均"到"瞬时"的跨越

📝 导数计算的三个步骤

1
求函数增量
计算 Δy = f(x+Δx) - f(x)，表示当自变量变化Δx时，因变量的变化量。
2
求平均变化率
计算比值 Δy/Δx = [f(x+Δx) - f(x)] / Δx，表示在区间[x, x+Δx]上的平均变化快慢。
3
取极限求瞬时变化率
令Δx趋近于0，求极限 f'(x) = limΔx→0 Δy/Δx，得到瞬时变化率。

💡 经典例题：用定义求导数

问题：用导数定义求函数 f(x) = x² 在 x = 3 处的导数。

Step 1: 设自变量在 x = 3 处有增量 Δx，则函数增量为：
Δy = f(3+Δx) - f(3) = (3+Δx)² - 3² = 9 + 6Δx + (Δx)² - 9 = 6Δx + (Δx)²
Step 2: 求平均变化率：
Δy/Δx = [6Δx + (Δx)²] / Δx = 6 + Δx
Step 3: 取极限求导数：
f'(3) = limΔx→0 (6 + Δx) = 6

🎓 本节要点总结

  • 导数的定义：f'(x) = limΔx→0 [f(x+Δx) - f(x)] / Δx
  • 几何意义：曲线在某点的切线斜率
  • 物理意义：瞬时变化率（如速度、加速度）
  • 核心思想：通过极限实现从"平均"到"瞬时"的跨越
  • 计算步骤：求增量 → 求比值 → 取极限
  • 切线逼近：割线斜率的极限就是切线斜率
