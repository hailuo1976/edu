微积分基础

探索变化率与累积的数学之美

导数

导数描述函数在某一点的瞬时变化率，是微积分的核心概念之一。

f'(x) = limh→0 [f(x+h) - f(x)] / h

几何意义：曲线在该点切线的斜率

积分

积分是导数的逆运算，用于计算曲线下的面积和累积量。

∫ab f(x) dx = F(b) - F(a)

几何意义：曲线与x轴之间的有向面积

核心定理

微积分基本定理

建立了微分与积分之间的桥梁，揭示了它们互为逆运算的关系。

d/dx ∫ax f(t) dt = f(x)
链式法则

[f(g(x))]' = f'(g(x))·g'(x)

乘积法则

[f·g]' = f'g + fg'

商法则

[f/g]' = (f'g - fg')/g²
